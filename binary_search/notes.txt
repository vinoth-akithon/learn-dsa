2. Boundary Search (First True/ Last True)
    - searching for the boundary (Instead of exact value) where a condition flips
    - Monotonicity -> condition flips exactly once (if flips more than one -> BS breaks)
        - for all x < k: condition(x) = False
        - for all x >= k: condition(x) = True

    - 2 sub patterns
        - Lower bound -> First True -> ceil
        - Upper bound -> Last True -> floor

3. Answer space Binary Search
    - Instead of search through the array, search through possible `Answer`
    - find the min value of X such that some condition holds
    - find the max value of x such that some condition holds

    - Transform optimization problem -> decision problem
    - Most powerful and hidden pattern

    ex:
        - what is the minimum speed S? --> Is the speed S is feasible?
        now BS on S from [min_possible, max_possible] 

    - Hint to Identify Answer Space BS
        - Minimum possible X such that...
        - Maximum possible X such that...
        - Minimize the Maximum
        - Maximize the minimum
        - answer is a number (not index)
        - feasibility can be checked in O(n) or O(n log n)
